# 英文家教

看中文、用英文回答（打字或錄音），由 Gemini 批改文法並評發音。課文從 Google 雲端硬碟匯入（Google 文件、Word 檔），練習紀錄存在雲端硬碟的「英文家教資料.json」，手機和電腦同步。

```
手機/電腦 ──▶ 網頁（GitHub Pages，index.html）
                 │  帶通行碼呼叫
                 ▼
            Apps Script 後端（Code.gs）：金鑰、紀錄、讀雲端硬碟
                 ▼
            Gemini API
```

網頁要放在 GitHub Pages，是因為 Apps Script 的網頁不能使用麥克風。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁（GitHub Pages） |
| `js/*.js` | 網頁程式，依 index.html 的順序載入 |
| `sw.js`、`manifest.webmanifest`、`icons/` | 安裝到手機桌面（PWA） |
| `Code.gs` | 後端，貼到 Apps Script |
| `tests/run.js` | 離線測試（`node tests/run.js`），模擬 Google 服務，不是真實環境 |

網頁裡沒有金鑰、通行碼或雲端硬碟資料夾，這些都存在 Apps Script 或使用者的瀏覽器裡，所以這個儲存庫可以公開。

## 後端部署（Apps Script）

1. 打開英文家教的 Apps Script 專案，把 `程式碼.gs` 的內容全部換成 `Code.gs`，存檔。
2. 原本的 `Index.html` 檔可以刪掉（後端不再提供網頁）。
3. **產生通行碼**：上方函式選單選 `setupToken` → 按「執行」→ 下方「執行記錄」會顯示「你的通行碼：xxxx」，複製起來。
4. **部署 → 管理部署作業 → ✏️ 編輯**：
   - 版本：**新版本**
   - 執行身分：**我**
   - 誰可以存取：**任何人**（網頁在 GitHub 上，必須這樣才連得到；靠通行碼擋陌生人）
5. 部署後複製網址（結尾 `/exec`）。

## 網頁設定（每支手機、每台電腦第一次用時）

1. 打開 <https://lamp4615-design.github.io/english-tutor/>
2. 設定頁輸入 **通行碼** → 連線（後端網址已寫在 `index.html` 的 `DEFAULT_API_URL`；換部署網址時要改這裡）。
3. 手機可以「加到主畫面」。

## 之後更新

- 改 `index.html`：推到 GitHub，約 1 分鐘後生效。
- 改 `Code.gs`：貼到 Apps Script → 管理部署作業 → 編輯 → 新版本 → 部署。
- 通行碼外流時：重新執行 `setupToken`，各裝置重新輸入新的通行碼。

## 狀態（2026-11-03）

- 激勵設計（A 批）：首頁今日任務卡（每日目標、進度圈、一鍵開始）、連續天數（每週 1 天補休；開車聽滿 10 分鐘也算）、熟練度 🌱🌿🌳⭐（由複習間隔換算）、12 週練習日曆、練習結束的鼓勵（只跟自己比）、待複習太多時自動分散到之後幾天、批改先說做對的地方。每天的紀錄存在資料檔的 `stats.days`，連續天數每次即時計算。
- 多元題型（B 批）：👂 聽音選意思、🧩 句子重組、✏️ 克漏字（常錯介系詞／冠詞時優先挖那種字）、🗣️ 跟讀（只評發音，4 分以上算對）、💬 看中文說英文。智慧模式依複習階段自動選：第 0 階聽、第 1 階排、第 2 階填空／跟讀輪流、第 3 階以上自己說；簡單題型答對最多升到第 1／2／3 階，要自己說對才能到精熟。聽、排、填空在網頁直接判斷，不用 Gemini。
- 進階（C 批）：「進度」分頁（這週和上週、發音分數趨勢、錯誤類型每 10 句幾次的 6 週變化，都有「看數字」表格）；🎯 弱點專練（Gemini 針對最近兩週常錯的類型出 5 句新句子，存成一課、進複習排程）；📬 每週教練信（每週第一次打開時依上週紀錄寫，上週沒練不寫）；💬 情境對話（Gemini 用課文設計情境、扮演對方，6 句，打字或錄音，每句即時回饋，算進當天練習量）。每天紀錄多存發音分數 `pr`／`prn`，教練信存在 `stats.letters`。
- 程式拆在 `js/`：core（常數、連線、存檔、提示詞）→ stats → audio → practice → modes → progress → chat → car → lessons → settings（啟動，要最後載入）。新增檔案時也要加進 `sw.js` 的 SHELL。
- 開車聽：中文 → 停頓 → 英文 →（慢速英文）合成一個音檔，螢幕關掉也能播，支援方向盤上一首／下一首。
- 可安裝到手機桌面（PWA）。

- Apps Script 版已在手機實測：匯入、批改、存檔正常；網頁內麥克風被 Apps Script 擋住，因此改成這個架構。
